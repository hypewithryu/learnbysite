# LearnOrbit — search any skill, learn it for free

Type anything you want to learn (guitar, Python, Spanish, baking…) and get **verified YouTube videos, articles, free books & courses, tips, a 4‑week plan and direct links** on one clean page. Interactive 3D hero, dark/light theme, installable on phones, and it keeps itself up to date.

## Go live in 3 steps

1. **Set your brand & domain** – edit `src/site.config.json` (name, tagline, owner, twitter), then run
   ```bash
   node scripts/seo.mjs https://your-domain.com
   ```
   This writes your canonical URL, Open Graph / Twitter tags, structured data, `sitemap.xml` and `robots.txt`.
2. **Build:** `npm run build` → upload the `dist/` folder to any static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages, your own server).
   No server rules are needed: pages are `/?q=skill`, which works on every host.
3. **Tell Google:** add your site in [Google Search Console](https://search.google.com/search-console) and submit `https://your-domain.com/sitemap.xml` (also Bing Webmaster Tools).

> Brand images (logo, app icons, 1200×630 share card) come from `node scripts/make-brand.mjs` (needs `npm i -D sharp`). Re-run it after changing the name/tagline.

## How it stays fresh by itself

| What | How |
| --- | --- |
| Search results | Fetched **live** on every search from Wikipedia, Wikiversity, Wikibooks, Open Library, DEV Community and YouTube (cached for a short time, stale copy used if a source is down). |
| Verified video catalog | `.github/workflows/refresh-content.yml` re-checks all videos every Monday (`scripts/fetch-videos.mjs`) and commits. Your host redeploys on the commit. Run it by hand any time: `node scripts/fetch-videos.mjs`. |
| Sitemap & meta tags | Regenerated by the same weekly job (`scripts/seo.mjs`). |
| New site versions | Every visitor's browser checks for a newer deploy (on load, every 10 min, when the tab regains focus). When found, a banner appears and the update is applied on their next search. A network-first service worker guarantees nobody is stuck on an old copy. |
| Skill of the day / trending | Rotates daily / pulls this week's top beginner posts live. |

## No broken links, no cracked content ("Link Guard")

- Results come live from their source, so URLs are real today.
- Catalog videos pass YouTube's oEmbed check (exists **and** embeddable).
- A video whose thumbnail fails to load is hidden automatically.
- A piracy filter drops cracks, keygens, torrents and re‑uploaded paid courses (`src/lib/safety.ts`). Searches such as "photoshop crack" are redirected to the legitimate skill and set to `noindex`.
- The **Direct links** hub only uses search/landing URLs of official platforms, so they can't go stale. Every external link opens in a new tab with `rel="noopener noreferrer"`.
- Every section has a fallback link (e.g. "Search YouTube"), so users never hit a dead end.

## Optional upgrades

- **Official YouTube search:** create a YouTube Data API key and build with `VITE_YOUTUBE_API_KEY=your_key npm run build`. Without it the site uses a keyless public search relay and falls back to the verified catalog.
- **More relays:** `VITE_PIPED_INSTANCES="https://pipedapi.example1,https://pipedapi.example2"`.
- **Add skills:** add entries to `src/data/topics.json`, run `node scripts/fetch-videos.mjs "My Skill"` then `node scripts/seo.mjs`.

## Hosting notes

- `index.html` contains the whole app, so it must be revalidated on every request — `public/_headers` (Netlify / Cloudflare Pages) and `vercel.json` already do that.
- `public/404.html` turns friendly URLs such as `/python` into `/?q=python`.
- Works from a sub‑folder too (everything is relative or inlined).

## Scripts

```bash
npm run dev                     # local development
npm run build                   # production build -> dist/
node scripts/seo.mjs <domain>   # sitemap, robots, meta tags
node scripts/fetch-videos.mjs   # refresh verified videos (--missing for gaps)
node scripts/make-brand.mjs     # regenerate logo / icons / share image
```
